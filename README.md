# Anand Paswan — UI/UX Portfolio (2026 redesign)

A responsive, editable portfolio landing page made with HTML, CSS, JavaScript and Tailwind utility classes (Tailwind Play CDN is referenced for optional enhancement; custom CSS keeps the design functional without it).

## Start
Open `index.html` in any modern browser, or put the entire folder on a static host (GitHub Pages, Netlify, Vercel, etc.). Keep the `assets` directory beside the HTML file. Internet is helpful for the optional Google Fonts and Tailwind CDN; all essential styles, scripts and imagery are local.

## Files
- `index.html` — portfolio landing page
- `style.css` — colors, spacing, visuals, animations, responsive layouts
- `script.js` — navigation, filtering, accessibility, project case-study popups
- `assets/*.webp` — five original code-generated UI concept preview images
- `assets/favicon.svg` — portfolio favicon
- `Anand_Paswan_Resume.pdf` — résumé download

## Integrity note
The five UI preview images are *new visual concepts* created for this portfolio. They are inspired by projects listed on the original résumé; they are not verified screenshots of shipped products, real performance outcomes, or design work for a paying client. Sample data shown in mockups is fictional illustration data. The résumé describes professional software-development experience; six months of UI/UX design practice reflects the portfolio positioning requested for this version, not a verified separate job.

## Edit
Change texts in `index.html`, the `projects` object in `script.js`, design colors at the top of `style.css`, and replacement previews in `assets` as your real case studies develop.

## Test checklist
- Desktop, tablet and mobile responsive layout
- Mobile menu open/close
- Project filters: all, dashboards, web apps, mobile
- All five case study buttons and Escape to dismiss
- Links: email, LinkedIn, local résumé download
- Reduced-motion setting
